개인정보처리방침

시행일 2026년 11월 3일

코칭일지 앱(이하 “앱”)은 개인정보를 수집하지 않습니다. 앱에 입력하거나 녹음한 내용은 사용자의 기기와 사용자 본인의 iCloud 계정에만 저장되며, 개발자는 이 정보에 접근할 수 없습니다.

1. 저장되는 정보

  • 코칭 기록: 날짜, 시간, 고객 이름, 코칭 구분, 주제와 메모
  • 녹음 파일과 변환된 텍스트
  • 설정: 응시자 명, 준비 중인 자격증, 코칭 교육 시작일, 앱 잠금 여부

이 정보는 앱 저장 공간과 사용자 본인의 iCloud(Apple의 CloudKit 개인 데이터베이스)에 보관되어, 같은 Apple 계정으로 로그인한 기기끼리 동기화됩니다. 녹음 파일은 사용자가 설정에서 ‘녹음 파일도 백업’을 켰을 때만 iCloud에 올라갑니다. 개발자의 서버로는 어떤 정보도 전송되지 않습니다.

기기 설정의 iCloud 항목에서 이 앱을 끄면 백업이 멈춥니다. 앱에서 기록을 삭제하면 iCloud에서도 지워지고, 앱만 삭제하면 iCloud의 기록은 남아 다시 설치했을 때 돌아옵니다.

2. 사용하는 기기 기능

  • 마이크: 사용자가 코칭 녹음을 시작할 때만 사용합니다.
  • 음성 인식: iOS 26 · macOS 26 이상에서는 기기 안에서 처리합니다. 이전 버전에서 “기기 내 인식만 사용”을 끄면 음성이 Apple의 음성 인식 서버로 전송될 수 있으며, 이때는 Apple의 개인정보 처리방침이 적용됩니다.
  • Face ID · Touch ID · 기기 암호: 앱 잠금을 켰을 때만 사용합니다. 앱은 생체 정보를 받지 않고 잠금 해제 결과만 시스템에서 전달받습니다.
  • 파일: 사용자가 고른 오디오 파일을 가져오거나, 내보내기를 고른 파일을 사용자가 정한 곳에 저장합니다.

3. 제3자 제공과 추적

앱에는 개발자의 서버, 광고, 분석 도구, 추적 기능이 없습니다. 개인정보를 제3자에게 제공하거나 판매하지 않습니다. 내보내기나 공유는 사용자가 직접 고른 경우에만, 사용자가 고른 곳(메일, 메시지, 파일 등)으로 전달됩니다.

4. 고객 정보와 녹음 동의

코칭 녹음은 반드시 고객의 동의를 받은 경우에만 사용해 주세요. 내보낸 파일과 공유한 텍스트에는 고객 정보가 들어 있으니 주의해서 다뤄 주세요.

5. 아동의 개인정보

앱은 어떤 사용자의 개인정보도 수집하지 않으며, 아동을 대상으로 하지 않습니다.
